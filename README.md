# WRN API

Minecraft **26.3** Plugin für Spigot/Paper mit **Java 25**.

## Bauen

```sh
mvn -B -ntp clean verify
```

Das Plugin liegt anschließend unter `target/wrn-api-1.0.jar`. Kopiere die JAR in den `plugins/`-Ordner eines Minecraft-26.3-Servers und starte ihn mit Java 25. LifeCore benötigt diese aktuelle WRN-API-JAR als separates Plugin.
